# Concept kinds (explorer default)

The explorer's three core kinds; the knowledge base's `kb.toml` `[types]` names the concrete page types, and
its own `digest/types.md` says what each means for it.

- **Source**: the digest of one raw item (a paper, a clip, a mail thread, a chat). Faithful, dated, cites `raw:`.
- **Collection**: a table grouping sources (a book's parts, a course's sessions, a series of posts).
- **Concept**: knowledge across sources. The default concept types are idea (one claim or construction),
  topic (a theme page, one per `area:`), question (something still open) and person.
