# Digest focus (explorer default)

What matters when a source is digested into this knowledge base. A knowledge base overrides this file with
its own `digest/focus.md`; this default applies when it has none.

- Keep the source page faithful to the raw item: what it claims, how it argues, what it leaves open.
- Pull out the concepts the knowledge base grows (see `types.md`) and link them with bare wikilinks.
- Prefer one clear idea per concept page over long summaries; cite the raw file in `raw:`.
- Record disagreements with existing pages as Connections bullets, never silent rewrites.
