# kb.toml

`kb.toml` at the root of a folder makes it a knowledge base. The folder name is the id.

## Example

`examples/demo/kb.toml` is a complete file. This is the shape:

```toml
[kb]
id = "my-kb"
name = "My KB"
schema_version = "1.5"
kit = "base"

[git]
tag_prefix = "kb-"

[types]
order = ["topic", "idea", "question", "person", "series", "article", "notes", "document", "company"]
source_fields = ["company", "date", "stage"]

[types.concept.company]
label = "Company"
prefix = "company-"
color = "#9ece6a"

[edges]
types = ["extends", "uses"]

[storage]
connector = "local-folder"

[publish]
publisher = "none"
```

## [kb]

| Key | Meaning |
|---|---|
| `id` | The id used by `--kb`. Lowercase letters, digits and dashes. |
| `name` | Display name. |
| `schema_version` | `major.minor` of the page schema. The engine refuses a knowledge base whose version differs from its own and tells you to run `distill ops migrate`. |
| `kit` | The kit the knowledge base follows: `base` or `research`. Without it, the file carries its own `[types]` and `[edges]`. The older key `template` is read too, and the old names `starter` and `academic-research` map to `base` and `research`. |

The current `schema_version` is `1.5`. The key `[kb] owner` is an id that the frontmatter migration writes into `generated: {by: human:<owner>}` for summaries you wrote by hand.

## [git]

| Key | Meaning |
|---|---|
| `tag_prefix` | Prefix of version tags. Default `kb-`, which gives `kb-1.4.2`. |

## [types]

Page types, by layer: `source`, `collection`, `concept`. The tables merge with the kit's. See [Kit](../concepts/kit.md).

| Key | Meaning |
|---|---|
| `order` | Every type once, in display order. |
| `areas`, `deprecated_areas` | The whitelist for the `area:` field. Each area needs a `theme-<area>` topic page. |
| `source_fields` | Extra frontmatter fields allowed on source pages. |

A type table, for example `[types.source.paper]`:

| Key | Meaning |
|---|---|
| `label` | Required. Display name. |
| `prefix` | Filename prefix. `""` means the bare slug. |
| `yeared` | The filename year must match the `year:` field. |
| `status` | Allowed status values. `[]` means none. |
| `kind` | Collections only: `partition` (a page range of its own PDF) or `contents` (member files in a table). |
| `color` | Optional. A palette color is chosen otherwise. |

## [edges]

| Key | Meaning |
|---|---|
| `types` | Relation kinds a page may state. |
| `symmetric` | Kinds stored once for both ends. |
| `note_required` | Kinds that need a one-sentence note. |
| `labels` | Display labels. |

## [storage]

```toml
[storage]
connector = "local-folder"      # or "gdrive", or a name a package registers
[storage.options]               # keyword arguments passed to the connector
```

Without this table, the local folder at the knowledge base root is used. See [Add a storage connector](../guides/add-a-storage-connector.md).

## [publish]

```toml
[publish]
publisher = "cloudflare"        # or "none", or a name a package registers
[publish.options]
```

See [Publishing](../concepts/publishing.md).

## [proposals]

```toml
[proposals]
auto_apply = ["links", "format", "typos"]     # hunk classes applied without review (when the producer asks)
review     = ["claims", "structure", "new_page"]
explicit   = ["tombstone", "merge", "split", "rename"]   # always need an explicit decision
```

Optional. Every key you leave out keeps the kit default shown here. See the trust tiers section of `defaults/docs/proposals.md`.

## Other files in a knowledge base

| Path | Meaning |
|---|---|
| `digest/focus.md`, `digest/types.md` | Instructions put in front of digest prompts. A missing file falls back to the engine default. `distill digest instructions` prints the result. |
| `meta/ops/sync.toml` | Settings of the nightly job, including `[notify]`. |
| `meta/aliases.tsv` | Old slugs of renamed pages. |
| `meta/corpus.tsv` | The manifest of raw files. Generated by `distill lint`. |
| `meta/coherence-warnings.tsv` | Findings of the semantic checks. |
| `.claude/` | Skills, docs, hooks and settings copied from the kit by `distill init`. |
