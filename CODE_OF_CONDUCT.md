# Code of conduct

Be kind and be useful. This project is a place to build a tool for thinking, and everyone who takes part should be able to do that without being harassed.

- Treat others with respect. Disagree with the idea, not the person.
- No harassment, discrimination, personal attacks, or publishing someone else's private information.
- Assume good faith, give specific and actionable feedback, and accept it the same way.
- Keep issues, pull requests and reviews on topic.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may ask a person to stop taking part. To report a problem, open an issue marked "conduct" without private details, or contact a maintainer through the address on their GitHub profile.
