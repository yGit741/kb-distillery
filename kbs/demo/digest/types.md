# Concept kinds — job search

- **company** (`company-*`): one employer; its process page lists every source about it.
- **role** (`role-*`): one position applied for; status seed → growing → solid as the picture fills in.
- **person** (bare slug): recruiter, hiring manager, interviewer, referral.
- **interview** (`interview-*`): one conversation; status scheduled → done → cancelled.
- **skill** (`skill-*`): something postings ask for or interviews test; links the sources that mention it.

Sources: posting (web clip), mail (recruiter thread), chat (AI interview prep), notes (interview notes),
document (CV and the like). Collection: process (one hiring process per company, listing its member files).
